# Machine Learning

This repository contains implementations, experiments, and educational
examples of machine learning algorithms.

## Topics

### 1. Supervised Classification

Classification algorithms implemented and demonstrated with Python.

- K-Nearest Neighbors (KNN)
- Logistic Regression
- Decision Tree
- Random Forest
- Support Vector Machine (SVM)
- Ensemble Learning
- Generative vs Discriminative Models

## Tools and Libraries

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## Purpose

The repository is intended for:

- Understanding machine learning algorithms
- Mathematical and conceptual demonstrations
- Python implementations
- Visualization of algorithms
- Teaching and learning
- Research experimentation
